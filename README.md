# ComponentCorner

A simple React store homepage made with reusable components.

## Run

```bash
npm install
npm run dev
```

## Files

- `src/components/Header.jsx` + `Header.css`
- `src/components/Hero.jsx` + `Hero.css`
- `src/components/ProductCard.jsx` + `ProductCard.css`
- `src/components/Footer.jsx` + `Footer.css`
- `src/App.jsx` renders 1 Header, 1 Hero, 3 ProductCards, and 1 Footer

Component CSS was generated with AI assistance.
